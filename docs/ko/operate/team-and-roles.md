# 팀·역할·토큰

대시보드 **Settings**에는 왼쪽 사이드 내비게이션에서 접근할 수 있는 세 개의 하위 페이지가 있습니다.

## Default

현재 로그인한 사용자의 개인 프로필 설정입니다.

- **Workspace** — 팀 이름과 로고를 설정합니다. Admin에게만 보입니다.
- **Apps** — 앱 이름을 바꾸거나 앱을 삭제합니다. Admin, Developer, QA에게 보이고 Viewer에게는 보이지 않습니다.
- **Nickname** — 댓글과 세션 히스토리에 표시됩니다.
- **Avatar** — 아바타의 연필 아이콘을 클릭해 이미지를 업로드합니다 (PNG 또는 JPEG, 최대 2MB).
- **Change password** — 현재 비밀번호가 필요합니다.

## Team

**Admin 전용**으로 표시됩니다.

- **Members list** — 전체 계정 목록 (이메일, 역할, 가입 날짜).
- **Invite member** — 이메일 초대 발송 또는 직접 공유용 링크 생성. 초대는 **7일** 후 만료됩니다.
- **Change role** — 멤버의 역할 재지정 (Admin / Developer / QA / Viewer).
- **Remove member** — 계정을 영구 삭제합니다. 그 팀원은 모든 곳에서 즉시 로그아웃되고 열려 있던 기기 세션과 그 팀원의 토큰으로 연결된 에이전트도 끊깁니다. 자기 자신은 삭제할 수 없습니다.
- **Reset pwd** — 멤버의 비밀번호 재설정 링크를 만듭니다. 링크는 다이얼로그에 표시되어 복사해 전달할 수 있고 SMTP가 설정되어 있으면 이메일로도 발송됩니다. 2시간 동안 한 번만 쓸 수 있으며 새 링크를 만들면 이전 링크는 동작하지 않습니다. 재설정하면 그 멤버는 모든 브라우저에서 로그아웃됩니다.

## 팀원 초대 {#invite-teammates}

Admin으로 로그인한 뒤 **Settings → Team**에서 초대 링크를 만듭니다.

1. **Invite member**를 클릭합니다.
2. 팀원의 이메일과 역할을 선택합니다. 역할의 기본값은 **QA**입니다.
   - **Admin** — 자기 계정 삭제를 빼고 모든 작업을 할 수 있습니다. 팀원 초대·역할 변경·삭제, 비밀번호 재설정, 워크스페이스 설정, **Settings → Tokens** 페이지는 Admin만 사용할 수 있습니다.
   - **Developer**, **QA** — 앱 추가·수정·삭제, 빌드 업로드, 빌드 상태 변경, 빌드 삭제 예약, 웹훅 관리를 할 수 있습니다. 두 역할의 권한은 같습니다.
   - **Viewer** — 읽기 전용입니다. 빌드를 보고 QA 세션에서 시뮬레이터나 에뮬레이터로 테스트하고 댓글을 남길 수 있습니다. 빌드와 앱은 바꿀 수 없습니다. 웹훅은 조회도 변경도 할 수 없습니다.

   댓글 작성과 세션 시작은 역할과 관계없이 로그인한 팀원 누구나 할 수 있습니다. 역할을 바꾸면 역할을 확인하는 API에는 팀원이 다시 로그인하지 않아도 바로 적용됩니다.
3. **Generate invite link**를 클릭합니다. 초대 링크가 다이얼로그에 표시되며 브라우저가 허용하면 클립보드에도 복사됩니다. SMTP가 설정되어 있으면 팀원에게 비밀번호 설정 링크가 담긴 초대 이메일도 발송됩니다. 이미 멤버인 이메일이면 초대가 거절되고 이메일 입력란 아래에 그 이유가 표시됩니다.

릴레이 호스트에서 `localhost`로 대시보드를 열었다면 초대 링크에는 릴레이 호스트의 LAN 주소가 들어갑니다. Docker 컨테이너 안의 릴레이는 LAN 주소를 알 수 없어서 브라우저 주소창의 주소를 그대로 씁니다. 터널이나 `relay.url`이 설정되어 있으면 그 주소가 들어갑니다. SMTP가 설정되지 않았다면 다이얼로그에 표시된 링크를 복사해 직접 공유하세요. SMTP 설정 방법은 [설정 파일](/ko/reference/configuration)을 참고하세요. 초대를 받은 팀원이 하는 일은 [팀원 시작 가이드](/ko/get-started/teammates)에 있습니다.

## Tokens

CI/CD 스크립트와 API 접근을 위한 개인 액세스 토큰(PAT)을 관리합니다. 사이드바에는 **Admin**에게만 표시됩니다.

- **New token** — 이름, 만료 기간(**Expiration**), 종류(Type)를 입력합니다. 만료 기간은 7·30·60·90일, 직접 입력(1~365일), **No expiration** 중에서 고르며 기본값은 30일입니다. 만료 기간이 없는 토큰은 폐기할 때까지 유효하므로 CI용이라면 90일 이하를 권장합니다. 목록에서는 이런 토큰에 **No expiration**이 표시되어 정리할 토큰을 찾을 수 있습니다. **API**는 CI 업로드와 API 접근용이고(`view, builds:write` 권한), **Agent**는 원격 Mac 에이전트 연결용입니다. 토큰은 생성 직후 한 번만 표시됩니다. 즉시 복사하세요.
- **Revoke** — 즉시 토큰을 무효화합니다.

CI에서 빌드를 업로드할 때 `Authorization: Bearer tflw_pat_<token>` 헤더로 사용합니다. [CI에서 빌드 올리기](/ko/operate/ci-distribution)를 참고하세요.
